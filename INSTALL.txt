ETLab MITS Reskin v1.2.0 - Local Install Guide

This is a 100% client-side browser extension for https://mits.etlab.app/

Installation (Chrome / Edge / Brave):
1. Open chrome://extensions/ (or edge://extensions/)
2. Turn on "Developer mode" (top-right toggle).
3. Click "Load unpacked" (top-left button).
4. Select this unzipped folder (or load the release ZIP in Kiwi/Lemur browser on Android).
5. Open https://mits.etlab.app/user/dashboard

Keyboard Shortcuts:
- Press "/" or Ctrl+K / Cmd+K to open smart search.
- Press Esc to close search and popovers.

Features:
- Concept 7 Dual-Tone Split Badge action tiles.
- 8 high-contrast glowing tile color themes.
- Live attendance & KTU activity point progress meter.
- Unified academic calendar with interactive date previews.
- Dark and Light mode toggle via extension popup or floating button.

Privacy & Security:
- Zero data collection, no telemetry, no external servers.
- Uses your active ETLab browser session.
- Passwords and credentials are never touched.
